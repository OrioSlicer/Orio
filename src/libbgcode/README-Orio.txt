libbgcode for Orio
==========================

Prusa binary G-code (.bgcode), written when the printer setting "binary_gcode" is on (Prusa MINI, MK3.5, MK3.9,
MK4, MK4S, XL, CORE One): the ASCII G-code is converted at export / upload time (BackgroundSlicingProcess.cpp).

Sources, the versions used by PrusaSlicer 2.9.6 (deps/+LibBGCode, deps/+heatshrink):
- LibBGCode/  https://github.com/prusa3d/libbgcode, commit 6f4ad7ce6b0e638b760199d6611039a610a5a479
              (zip SHA256 1e91c944a52022e8af46b05b463add59b3ac011a5e1982e60891d41149c56144), AGPL-3.0 (LICENSE).
              Only src/LibBGCode/core, binarize and convert.
- heatshrink/ https://github.com/atomicobject/heatshrink, v0.4.1
              (zip SHA256 2e2db2366bdf36cb450f0b3229467cbc6ea81a8c690723e4227b0b46f92584fe), ISC (heatshrink/LICENSE).

Changes, marked "Orio" in the code:
- core/export.h, binarize/export.h, convert/export.h: written by hand (generated by libbgcode's own CMake);
  LibBGCode_VERSION ("0.3.0", from pyproject.toml) defined in CMakeLists.txt.
- convert/convert.cpp, from_ascii_to_binary():
  · the header line "; Orio <version>" is accepted as producer (only "generated by PrusaSlicer" was);
  · a metadata key must be the whole name before "=" (the prefix matched "temperature_vitrification" as
    "temperature", "bed_temperature_formula" as "bed_temperature"...).
